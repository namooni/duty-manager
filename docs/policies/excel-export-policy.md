# Excel 내보내기 — 현재 구현

당번 상세의 「Excelをダウンロード」에서 저장된 담당 일정을 xlsx로 다운로드한다. 일본어 UI·일본 시간 기준이며 조회·다운로드는 담당을 생성하거나 변경하지 않는다. 이전 형식 당번은 대상이 아니다.

## 출력 선택

- 기본 기간은 상세 화면에서 보고 있던 연도의 1월 1일~12월 31일. 날짜로 변경할 수 있으며 기존 조회와 같은 최대 367일, 1900~2199년 제한을 적용한다.
- CALENDAR 교대는 「期間別担当表」, OCCURRENCE 교대는 「開催日一覧」를 추천한다. 사용자 변경을 허용한다. 실행 규칙 6개별 템플릿을 중복 구현하지 않는다.
- 개별 개최일의 미정 회차 포함 여부를 선택한다. 미정 회차에는 아직 연도가 없으므로 포함 선택 시 저장된 미정 회차 전체를 출력하며 화면과 문서에 이를 표시한다.
- 시작 전·운영 종료 후 기간은 대상에서 제외한다. 배정 범위 이후의 미배정 구간은 화면과 파일에 안내하고 임의 배정을 만들지 않는다. 출력할 행이 없어도 설명이 있는 파일을 제공한다.

## 템플릿

| 서식 | 열 | 권장 용도 |
| --- | --- | --- |
| 期間別担当表 | 実施日 / 担当者 | 주간·월간 기간 담당 |
| 開催日一覧 | 回 / 開催日 / 曜日 / 担当者 / 備考 | 정례회·회차별 담당 |
| 実施日一覧 | 実施日 / 曜日 / 担当者 / 実施状況 / 備考 | 두 서식에 공통으로 추가되는 날짜별 상세 시트 |

기간별 표는 당번·교대 키·담당 구간·저장된 담당자 슬롯이 같은 실행일만 묶는다. 중도 인계 구간이나 다른 회차를 합치지 않는다. 날짜 범위는 요청 범위 내 휴일 아닌 실제 실행일로 계산한다. 주 표는 실시일과 담당자 두 열만 제공하고 번호·실시 횟수·비고는 표시하지 않는다. 회사 휴일·교대 경계·경고는 날짜별 상세 시트의 비고에 보존한다. 전체 휴일인 구간은 실행 없음으로 표시한다. 개최일 목록에는 휴일 행도 실행 없음으로 표시한다.

이름과 사번은 함께 표시하고 복수 담당자는 셀 안에서 줄을 나눈다. 일자별 상세에는 회사 휴일명도 표시한다. 개최일 미정은 「未定」로 표시하며 회차 번호는 원래 저장된 순서를 유지한다. 상세·개최일 목록의 날짜 셀은 Excel 날짜 타입, 사용자 입력 문자열은 수식으로 해석하지 않는 문자열 타입이다.

## 서식과 인쇄

- 짙은 회색 헤더, 흰색·연회색 행, 회사 휴일은 회색, 미정 회차는 옅은 황색.
- Yu Gothic 기본 글꼴, 이름·비고 줄바꿈, 고정 열 너비, 제목·대상 기간·실행 규칙 표시. 기간별 주 표는 종류명·영문 장식·출력 시각을 생략하고 연도를 상단에 모아 날짜는 8月3日～8月7日처럼 표시한다. 여러 해의 출력에는 연도 구분 행을 넣고, 한 담당 구간 자체가 연도를 넘는 행만 양끝 연도를 표시한다. 개최일 목록과 날짜별 상세는 기존 메타데이터를 유지한다.
- 화면 눈금선 숨김, 헤더 고정(개최일 목록·상세는 필터 포함), A4 가로 1페이지 폭 맞춤(기간별 주 표와 개최일 목록은 세로 방향, 기간별 상세는 가로 방향). 세로 페이지 수를 강제로 1장으로 축소하지 않는다.
- 인쇄 시 열 제목 반복, 페이지 번호와 출력 영역 지정. 기간별 주 표는 연도·대상 기간을 포함한 상단도 반복해 두 번째 인쇄 페이지부터 연도가 누락되지 않게 한다.
- 공통 ScheduleWorkbookTemplate이 기본 서식을 소유하고 ScheduleWorkbookWriter가 두 레이아웃을 채운다. 외부 Excel 엔진이나 서버의 폰트 설치에 의존하는 자동 열 너비는 사용하지 않는다.

## API와 책임 분리

POST /api/automatic-duties/{id}/export

입력: from, to, format(PERIOD 또는 MEETING), includeUndated.
응답: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet, attachment, Cache-Control: no-store. 오류는 기존 JSON 계약을 따른다.

- Controller: 입력 검증·바이너리 HTTP 응답.
- ScheduleExportService: 공통 LiveScheduleService로 저장된 일정 조회·범위 안내 조립.
- ScheduleExportRows: 기간별 묶음·날짜별 행의 순수 변환.
- ScheduleWorkbookTemplate / Writer: Excel 서식과 직렬화.
- 프론트: useScheduleExport → repository → domain API → apiClient. 파일 저장은 libs/files/download가 담당한다. UI는 훅 상태를 표시하고 이벤트를 연결한다.

수정된 담당자·중도 인계·개최일을 그대로 반영한다. DB migration은 없다. 실제 회사 DB에 테스트 자료를 넣지 않는다.

## 샘플

[기간별 담당표](../examples/weekly-duty-sample-v2.xlsx), [개최일 목록](../examples/meeting-duty-sample.xlsx)은 가상 자료로 실제 출력 코드에서 생성한 예시다. 구현 검증은 POI로 생성 결과를 다시 열어 셀 타입·내용·인쇄 설정을 확인하고, H2 MySQL 모드에서 6개 규칙의 저장 무변경을 확인한다. 실제 Excel의 화면·프린터별 최종 레이아웃은 사용 환경에서 확인한다.

의존성: Apache POI 6.0.0 ([공식 배포 안내](https://poi.apache.org/), [Spreadsheet 가이드](https://poi.apache.org/components/spreadsheet/quick-guide.html)).
