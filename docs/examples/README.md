# Excel 출력 예시

실제 회사 자료가 아닌 가상 이름·일정으로 만든 샘플이다. 서버의 실제 ScheduleWorkbookWriter로 생성했으며 공통 스타일과 인쇄 설정을 사용한다.

- [주간 당번표](weekly-duty-sample-v2.xlsx): 한 달간 주간 담당, 회사 휴일, 주중 인계 예시. 실제 실행일과 담당자 두 열로 표시한다. 연도는 상단에 모으고 날짜는 10月5日～10月9日 형식이다. 회사 휴일과 교대 경계는 두 번째 시트에서 확인한다.
- [정례회 개최일 목록](meeting-duty-sample.xlsx): 2026/11~2027/10의 회차·담당자와 개최일 미정 2회 예시.

각 파일의 두 번째 시트는 「実施日一覧」다. A4 인쇄 미리보기에서 열 제목 반복과 페이지 번호를 확인할 수 있다. 파일은 수동으로 수정한 템플릿이 아니라 실제 출력 서식의 예시이며, 이후 서식 변경 시 ScheduleWorkbookWriterTest의 샘플 생성 테스트로 다시 만든다.
